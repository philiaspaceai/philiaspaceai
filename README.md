# Philia Space Community 🇮🇩🇯🇵

![Philia Space banner](./assets/banner.gif)

**Philia Space Community** adalah komunitas **belajar bahasa Jepang** dari Indonesia
(non-profit) dengan tiga peran:

- 📚 **Tempat belajar bareng** — diskusi, latihan, dan berbagi pengalaman belajar bahasa Jepang.
- 🛠️ **Tempat mengembangkan tools & resource belajar** — kamus, deck Anki,
  bot latihan JLPT, hingga skill AI agent, semuanya open-source.
- 🌍 **Tempat menampung dan mengkurasi resource** dari berbagai komunitas luar negeri
  seperti [TheMoeWay](https://learnjapanese.moe), agar mudah ditemukan dan dipakai
  pejuang bahasa Jepang Indonesia.

## 🚀 Proyek Unggulan

### 🥋 jlpt-dojo

Bot Discord **gratis** untuk latihan JLPT (N5–N1): 4.300+ soal kuis bahasa Jepang,
rank kompetitif, EXP, badge, dan kartu profil. Mencakup kanji, kosakata, tata bahasa,
dan reading.

➡️ <https://github.com/philiaspaceai/jlpt-dojo>

### 📖 yomitan-agent-skills

Skill AI-agent universal untuk **membuat, mengedit, memvalidasi, dan mengemas kamus
Yomitan** — bisa dipasang di 80+ AI agent (Claude Code, OpenCode, Codex, Hermes, …).

```bash
npx skills add philiaspaceai/yomitan-agent-skills
```

➡️ <https://github.com/philiaspaceai/yomitan-agent-skills>

### 🌿 philia-shizen

Kuasai Hiragana dan Katakana lewat pengulangan spaced-repetition yang elegan.

➡️ <https://github.com/philiaspaceai/philia-shizen>
