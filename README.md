## 🚀 Proyek Unggulan

### 🥋 jlpt-dojo

Bot Discord **gratis** untuk latihan JLPT (N5–N1): 4.300+ soal kuis bahasa Jepang,
rank kompetitif, EXP, badge, dan kartu profil. Mencakup kanji, kosakata, tata bahasa,
dan reading.

➡️ <https://github.com/philiaspaceai/jlpt-dojo>

### 📖 yomitan-agent-skills

Skill AI-agent universal untuk **membuat, mengedit, memvalidasi, dan mengemas kamus
Yomitan** — bisa dipasang di 80+ AI agent (Claude Code, OpenCode, Codex, Hermes, …).

```bash
npx skills add philiaspaceai/yomitan-agent-skills
```

➡️ <https://github.com/philiaspaceai/yomitan-agent-skills>

### 🌿 philia-shizen

Kuasai Hiragana dan Katakana lewat pengulangan spaced-repetition yang elegan.

➡️ <https://github.com/philiaspaceai/philia-shizen>
